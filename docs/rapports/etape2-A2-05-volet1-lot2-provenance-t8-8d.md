### `v_516` · ある · nuance d'ENTRY — **écart**

- **Fiche source** (`n5_v_516`, verbe) : mot ある (ある) ; traductions « Exister ; Y avoir ; Posséder ; Se trouver (pour les objets inanimés) » ; particules が, に.
