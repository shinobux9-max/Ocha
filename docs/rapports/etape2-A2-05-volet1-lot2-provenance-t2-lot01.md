### `v_23` · 友達 · nuance d'ENTRY — **sourcé**

- **Fiche source** (`n5_v_23`, nom) : mot 友達 (ともだち) ; traductions « Ami ; Copain ; Camarade » ; particules aucune. Nuance : « Nom courant désignant un ami ou une amie avec qui l'on entretient des liens amicaux. Le suffixe -tachi indique le pluriel mais est ici figé dans le mot. » Exemple : « 週末[しゅうまつ] に 友達[ともだち] と 映画[えいが] を 見[み]ます 。 » — « Ce week-end, je regarde un film avec un ami. »
  - Ancien exemple : « 私[わたし] は 友達[ともだち] と 映画[えいが] を 見[み]に行[い]きました » — « Je suis allé voir un film avec un ami. »
  - Ancien exemple : « 休[やす]み の 日[ひ] に 友達[ともだち] の 家[いえ] に あそび に 行[い]きます » — « Je vais jouer chez un ami pendant mon jour de repos. »
  - Ancien exemple : « 私[わたし] の 友達[ともだち] は 親切[しんせつ] な 人[ひと] です » — « Mon ami est une personne gentille. »
- **Publié** : nuance de l'ENTRY : « Désigne un ou plusieurs amis : 達 marque à l'origine le pluriel, mais 友達 s'emploie aussi pour un seul ami. ».
- **Décisions de l'ENTRY** : D0100 (abandon, `senses`) : « Un camarade de classe se dit クラスメート ; « ami, copain » couvre le sens. ».
- **Repérage** : un caractère seulement ; aucune chaîne signalée ; caractère isolé : 達.
- **Origine recherchée** : Nuance de la fiche : « Le suffixe -tachi indique le pluriel mais est ici figé dans le mot » ; mot de la fiche : 友達.
- **Verdict proposé** : **sourcé**.
- **Verdict arbitré (2026-10-10)** : **sourcé**, confirmé.
- **Justification** : Le caractère 達 n'est pas un mot ajouté : c'est l'élément du mot 友達, que la fiche écrit, et que la fiche elle-même identifie comme le suffixe du pluriel. La nuance publiée désigne cet élément sous la graphie que le mot de la fiche lui donne. Aucune graphie n'est reconstituée.
- **Réserve** : **Cas discutable** : la fiche nomme le suffixe en romaji (-tachi), non sous la forme 達 isolée. Si l'arbitrage tient qu'un élément ne peut être cité isolément que si la fiche l'isole, l'unité est un écart, et la correction serait : « Désigne un ou plusieurs amis : le suffixe marque à l'origine le pluriel, mais 友達 s'emploie aussi pour un seul ami. »
