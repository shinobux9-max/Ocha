## 7. Limites

- **Sept sens, et eux seuls.** Aucun autre sens n'est jugé, même comparable, même de la même ENTRY.
- **La fiche source décide.** Chaque fiche sera lue en entier, avec toutes les décisions de l'ENTRY ; rien n'est ajouté par connaissance externe.
- **Aucune symétrie n'est imposée** entre comparables ; une divergence n'est un écart que si une norme la tranche.
- **Une catégorie n'est pas cherchée pour réduire un compte** ; `category: null` (A5) et `semantic_type: null` (A6) restent légitimes.
- **Rien n'est appliqué** ; une correction proposée ne serait retenue que par l'arbitrage.
- **Ne sont pas ouverts** : l'examen lexical de B8 avant l'acceptation de ce périmètre ; les autres livraisons ; le bloc F et la recherche d'omissions (E5 ni adopté ni appliqué) ; HP-1 à HP-4 ; QC-1 et QC-2 ; G1 à G7 ; le balayage des relations.
