## 5. Cas de provenance à risque, relevés sans verdict

Ces relevés sont tirés des classes du tri, du journal, des relations publiées, des lots et des listes arbitrées ; ils signalent où un précédent s'appliquera ou devra être précisé. **Aucun ne préjuge du verdict d'une nuance, et aucune fiche source n'a été ouverte pour les établir.**

1. **Un mot que la fiche ne nommerait qu'en romaji** (22 nuances de classe B-romaji, dont 18 renvoient à une autre ENTRY : 下手 → 上手 ; 難しい → 易しい ; 新しい → 古い ; 強い → 弱い ; 弱い → 強い ; 遅い → 早い, 速い ; 汚い (sens 1) → きれい ; 静か → 賑やか ; 結婚 → する ; 生活 → する ; ある → 居る ; 居る → ある ; やる (sens 1) → する ; やる (sens 2) → 上げる ; それでは → じゃあ ; 少ない → 多い ; 少し → ちょっと ; 大体 → たいてい). C'est la configuration des contraires de 7c et de 7d. Les règles arbitrées s'appliquent telles quelles : la transcription en kana d'un romaji attesté est recevable, sans ajout de kanji ; **aucune exception ne permet d'importer les kanji d'une autre ENTRY** ; les éléments d'un mot que la fiche écrit elle-même sont sourcés. Chaque fiche sera lue pour elle-même : la chaîne publiée est parfois déjà en kana (はやい, きれい, ちょっと, たいてい, じゃあ, する, ある), parfois en kanji (上手, 易しい, 古い, 弱い, 強い, 賑やか, 居る, 上げる, 多い), ce que le tri ne distingue pas.
2. **Exemples publiés que le tri a retrouvés par transcription** (10 nuances : 出来る (sens 1), 終わる, 多い, 少ない, 大勢, 全部, 少し (sens 1), 結構 (sens 1), 一番 (sens 1), 大体 (sens 1)). La phrase publiée a été rapprochée d'un exemple de la fiche sous une autre écriture. Le contrôle vérifiera qu'elle est **exactement** celle de la fiche : mêmes mots, mêmes particules, même forme, mêmes graphies ; **le retrait d'un mot qui porte une information de l'exemple source n'est pas une simple réduction** (arbitrage de 7c : 低い et あまり, V2-152).
3. **Constructions avec un auxiliaire ou avec する** (座る : ている ; 立つ : ている ; 結婚 : する, 結婚する ; 生活 : する ; 困る : ている ; やる (sens 1) : する). Une forme conjuguée ou composée n'est pas sourcée d'office (critère 3 ; 自分 et やります, V2-144). Pour 結婚 et 生活, le lot 19 a validé `suru_compatible: true` : comme pour une relation structurée, **un champ structuré validé ne vaut pas, à lui seul, fondement d'un élément de nuance** ; les décisions seront lues dans leur texte exact.
4. **Relations publiées et ENTRY rouvertes à la passe finale** (lot 26). Relations portées par une ENTRY de la tranche : 少ない `v_447_s1` `opposed_to` 多い `v_654_s1`.
